DIAGRAM 2 — Environment Drift flow (Section: How each report works > Environment Drift)
----------------------------------------------------------------------------------------

flowchart TD
    A["Cloud Scheduler trigger"] --> B["Cloud Run Job starts\nloads GitLab token from Secret Manager"]
    B --> C["Clone all repos in FastOSS_B/ndl_core\nskip demo_* repos"]
    C --> D{{"For each repo\n(parallel)"}}
    D --> E["Parse DDL / dbt YAML\nfrom git branch\nproduction / test / master"]
    D --> F["Query BQ INFORMATION_SCHEMA\nin target GCP project"]
    E & F --> G["Compare schemas\nobject by object"]
    G --> H{{"Differences\nfound?"}}
    H -- "Yes" --> I["Write rows to\nenv_drift_findings\n(one row per drifted object)"]
    H -- "No" --> J["Write execution record\nto executions table\nstatus = success"]
    I --> J
    J --> K["Upload report.md\nto GCS bucket"]


DIAGRAM 3 — Commit Drift flow (Section: How each report works > Commit Drift)
------------------------------------------------------------------------------

flowchart TD
    A["Cloud Scheduler trigger"] --> B["Clone all repos"]
    B --> C{{"For each repo\n(parallel)"}}
    C --> D["Compare 6 branch pairs:\nmaster<>production\nmaster<>test\nproduction<>test\n(both directions each)"]
    D --> E["Find commits in right branch\nnot present in left branch\n(git log A..B)"]
    E --> F["Write KPI summary\nto branch_drift_kpis\n(one row per repo x direction)"]
    F --> G["Write commit detail\nto branch_drift_evidence\n(one row per commit x file)"]
    G --> H["Write execution record\nto executions table"]


DIAGRAM 4 — File Drift flow (Section: How each report works > File Content Drift)
----------------------------------------------------------------------------------

flowchart TD
    A["Cloud Scheduler trigger"] --> B["Clone all repos"]
    B --> C{{"For each repo\n(parallel)"}}
    C --> D["git diff --name-status\nbetween branch pairs"]
    D --> E["Classify each file:\nAdded / Modified / Deleted / Renamed"]
    E --> F["Write KPI summary\nto branch_drift_kpis\n(drift_type = content)"]
    F --> G["Write file detail\nto branch_drift_evidence"]
    G --> H["Write execution record"]


DIAGRAM 5 — Orphan Datasets flow (Section: How each report works > Orphan Datasets)
-------------------------------------------------------------------------------------

flowchart TD
    A["Cloud Scheduler trigger"] --> B["Cloud Run Job starts"]
    B --> C["List all BQ datasets\nin tefde-gcp-fastoss-prod\nvia INFORMATION_SCHEMA"]
    B --> D["Clone all repos\nfrom GitLab"]
    D --> E["Extract dataset references\nfrom DDL / dbt / CI files"]
    C & E --> F["Find datasets with\nno code reference"]
    F --> G["Score each orphan\nby risk: age x size x table_count"]
    G --> H["Write to orphan_datasets\nand orphan_dataset_objects"]
    H --> I["Write execution record"]
