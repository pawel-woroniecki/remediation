DIAGRAM 2 — Environment Drift flow (Section: How each report works > Environment Drift)
----------------------------------------------------------------------------------------

flowchart TD
    A["Cloud Scheduler trigger"] --> B["Cloud Run Job starts
loads GitLab token from Secret Manager"]
    B --> C["Clone all repos in FastOSS_B/ndl_core
skip demo_* repos"]
    C --> D{{"For each repo
(parallel)"}}
    D --> E["Parse DDL / dbt YAML
from git branch
production / test / master"]
    D --> F["Query BQ INFORMATION_SCHEMA
in target GCP project"]
    E & F --> G["Compare schemas
object by object"]
    G --> H{{"Differences
found?"}}
    H -- "Yes" --> I["Write rows to
env_drift_findings
(one row per drifted object)"]
    H -- "No" --> J["Write execution record
to executions table
status = success"]
    I --> J
    J --> K["Upload report.md
to GCS bucket"]


DIAGRAM 3 — Commit Drift flow (Section: How each report works > Commit Drift)
------------------------------------------------------------------------------

flowchart TD
    A["Cloud Scheduler trigger"] --> B["Clone all repos"]
    B --> C{{"For each repo
(parallel)"}}
    C --> D["Compare 6 branch pairs:
master<>production
master<>test
production<>test
(both directions each)"]
    D --> E["Find commits in right branch
not present in left branch
(git log A..B)"]
    E --> F["Write KPI summary
to branch_drift_kpis
(one row per repo x direction)"]
    F --> G["Write commit detail
to branch_drift_evidence
(one row per commit x file)"]
    G --> H["Write execution record
to executions table"]


DIAGRAM 4 — File Drift flow (Section: How each report works > File Content Drift)
----------------------------------------------------------------------------------

flowchart TD
    A["Cloud Scheduler trigger"] --> B["Clone all repos"]
    B --> C{{"For each repo
(parallel)"}}
    C --> D["git diff --name-status
between branch pairs"]
    D --> E["Classify each file:
Added / Modified / Deleted / Renamed"]
    E --> F["Write KPI summary
to branch_drift_kpis
(drift_type = content)"]
    F --> G["Write file detail
to branch_drift_evidence"]
    G --> H["Write execution record"]


DIAGRAM 5 — Orphan Datasets flow (Section: How each report works > Orphan Datasets)
-------------------------------------------------------------------------------------

flowchart TD
    A["Cloud Scheduler trigger"] --> B["Cloud Run Job starts"]
    B --> C["List all BQ datasets
in tefde-gcp-fastoss-prod
via INFORMATION_SCHEMA"]
    B --> D["Clone all repos
from GitLab"]
    D --> E["Extract dataset references
from DDL / dbt / CI files"]
    C & E --> F["Find datasets with
no code reference"]
    F --> G["Score each orphan
by risk: age x size x table_count"]
    G --> H["Write to orphan_datasets
and orphan_dataset_objects"]
    H --> I["Write execution record"]
